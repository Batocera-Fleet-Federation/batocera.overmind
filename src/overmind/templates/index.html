Built for arcades you can't babysit

Got Batocera machines you don't sit next to every day? That's exactly who Overmind is for.

  • Airbnbs & vacation rentals: give guests a polished arcade, lock it to Kiosk mode, and update or fix it remotely between stays — no trip to the property.
  • Home arcades & game rooms: keep every cabinet's games in sync from the couch.
  • Bars, cafes & businesses: manage a whole floor of machines, set volume, and restart anything from one screen.
  • Multiple properties or locations: one dashboard for every machine, wherever it lives.

Quick setup

Monitor and manage a machine in a few quick steps.

  1. Install the Drone. On the Batocera machine, open a terminal (SSH, or press F1 → file manager → terminal) and run:
curl -fsSL https://github.com/Batocera-Fleet-Federation/batocera.drone/releases/latest/download/batocera_install.sh | bash
  1. Open the Drone. Open it from any device on your network.
  2. Connect it. Create an Overmind account and register the Drone.
Done — the machine reports status and accepts remote actions.

Secure by design

Your machines and your network deserve real protection. Security was built in from the start, not bolted on:

  • Encrypted everywhere: all traffic runs over HTTPS, and machine-to-machine transfers use mutually-authenticated TLS (mTLS).
  • Certificate-pinned peers: Drones verify each other by certificate, so only the trusted machines in your swarm can connect or share files.
  • Your credentials stay yours: tokens and keys stay on each machine and are never shared between peers.
  • Locked-down access: admin tools sit behind authentication, with brute-force protection and rate limiting on unauthenticated requests.
  • You stay in control: new Drones must be explicitly approved before they join, and the whole project is open source so anyone can verify exactly how it works.

Quick start

Get a machine connected for monitoring and remote management.

  1. Install the Drone. On the Batocera machine, open a terminal (SSH, or press F1 → file manager → terminal) and run:
curl -fsSL https://github.com/Batocera-Fleet-Federation/batocera.drone/releases/latest/download/batocera_install.sh | bash
  1. Turn it on. Batocera v43+: System Settings > Services > enable DRONE_SERVER. Older versions: reboot.
  2. Open the Drone. The installer prints a green banner with the machine's address — usually https://batocera.local. Open it from any device on your network and sign in (user batocera, password linux).
  3. Connect to Overmind. Here in Overmind, open My Swarm > Generate Token. In the Drone app, open Admin > Overmind Integration, set the Overmind URL to https://www.batocera-swarm.com, paste the token, and save — then approve the Drone back in My Swarm.
Done! The machine now reports status and accepts remote actions.

What you can do from Overmind

  • Monitor every machine — online status, system info, storage, and gameplay history from one dashboard.
  • Manage remotely — open a Drone and use the Admin tab to turn Kiosk mode on/off, set Volume, Restart the machine, or rebuild its asset cache. Each request shows its progress under Recent Actions as it moves from pending to completed.
  • Sync content between cabinets — copy games and BIOS directly from one machine to another (artwork comes along automatically), so you set things up once and let the others pull it. (Needs the one-time router step below.)
  • Debug from your desk — read system info, storage, and network health without walking over to the cabinet.

Full setup: share files between machines

Monitoring and remote actions work as soon as a Drone is connected. One extra step lets your machines send games and BIOS to each other: you tell your router to pass incoming secure traffic (port 443) through to the Batocera machine. This is called port forwarding, and you only do it once per machine.

Not ready to share files? Skip this entirely. The Drone still connects for monitoring and remote actions — it just won't share files with other Drones.

1. Gather three things first

  • Your router's address — in the Drone app, open System Info and copy the Router IP Address (it looks like 192.168.1.1).
  • Your Batocera machine's IP address — also in System Info, or on the machine under Network Settings > IP Address (it looks like 192.168.1.50).
  • Your router's login — the admin username and password, usually printed on a sticker on the router itself.

2. Open your router's settings

Type the Router IP Address into a web browser on any device on your network, then sign in with the router login.

3. Find the port forwarding page

Look for a menu called Port Forwarding. Depending on the router brand it may be tucked under NAT, Firewall, Advanced, Gaming, or Virtual Server.

4. Add one new rule with these exact values

NameAnything you like, e.g. Batocera Drone
Device / Internal IPYour Batocera machine's IP address (not the router's)
External port443
Internal port443
ProtocolTCP (choose "TCP/UDP" or "Both" if TCP alone isn't offered)

5. Save it

Click Save (some routers say Apply or Add). A few routers need a quick reboot for the rule to take effect.

How to tell it worked: come back to Overmind, open the Drone, and check its connection. Within a minute or two it should show as reachable to the swarm, and other Drones can pull files from it.

If it isn't working: make sure you forwarded to the Batocera machine's IP (not the router's), that both ports are 443, and that the protocol includes TCP. Some home internet plans block incoming connections — if a correct rule still doesn't work, your internet provider may need to allow it.
